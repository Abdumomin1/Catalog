Этот файл читается в начале каждого чата с этим репозиторием. Подробности (как устроено, ID папок,
что сделано, план) — в `README.md`: **сначала прочитать его**, в конце чата обновить и запушить в `main`.

его здесь не трогать и про каталог туда не писать. Исключение — общая страница каталога: `index.html`

в обоих (в каждом своём чате).

## Владелец и как с ним работать

- Maff — дистрибьютор напольных покрытий и дверей в Узбекистане. Владелец — категорийный менеджер /
  закупщик, не программист. Обращаться «Phenomen». Общение на русском, без жаргона; спорить по существу.
- Вопросы — по одному. Перед заменой или удалением — посмотреть, что там лежит.
- Сессия облачная: файлы с ПК владельца (`C:\Users\...`) недоступны — просить перетащить папку в
  Google Drive. Режим **Auto** рядом с полем ввода избавляет от «Разрешить» на каждое действие с Drive.
- **Секреты в чат не принимать** (16.11 владелец прислал `.env` с ключами 1С, Eskiz, DeepL — их нужно
  сменить). 24.11 владелец сам дал ключ 1С для чтения: только GET-запросы, ключ нигде не сохранять.
  Подробности доступа к 1С — README, «1С напрямую».
- `script.google.com` из облака закрыт сетью: выдачу `EXEC?data=json` отсюда не увидеть. Код Apps Script
  лежит в `apps-script/` (копия от 18.11, не живая — в таблицу его вставляет владелец).
- Репозиторий **не делать приватным**: на бесплатном GitHub это выключит Pages, и каталог в боте
  перестанет открываться. Ключи (1С и др.) — только в «Свойствах скрипта» Apps Script, не в коде.

## Главные правила каталога

- Кнопка «Каталог» в @maff_uz_bot → `index.html` (GitHub Pages, ветка `main`: **пуш в `main` сразу
  виден партнёрам**) → Apps Script таблицы «Каталог» (`1JSCgXBTlrYnvWLD-bHXfp9DCtXOKgFXZEh1zn2bBoe4`)
  → фото из папки Drive «Каталог» (`1rsAAa7mngASsJ-kDwgLT69rKPP-wMGyO`, все подпапки).
- **Имя фото = номенклатура из 1С + `.jpg`**, точь-в-точь. На товар — ровно один такой файл во всём
  «Каталоге», иначе бот может взять не тот.
- Структура: `Каталог → Ламинат → Завод → Коллекция → фото`. Папки коллекций называть как группы 1С.
  Иерархию «завод → коллекция → номенклатура» брать из выгрузки 1С «Остаток товара (ОСНОВНОЙ)» (`.xlsx`,
  группы — строки без артикула), а не угадывать.
- **Кэш фото — 6 часов** (лист «Настройки»), на телефоне ещё свой кэш (открыть каталог дважды).
  Сбросить сразу: в таблице меню **«Каталог → Обновить сейчас»**. При замене фото сначала класть новый
  файл, потом убирать старый в архив, потом «Обновить сейчас» — иначе кэш запомнит удалённый файл.
- Заменённые фото не удалять — переносить в архив **вне** «Каталога» (папки в корне «Моего диска»).
- PNG по 1+ МБ переводить в JPG (качество 85, 1080 px ≈ 150–250 КБ). Скачанный с Drive файл
  сохраняется локально; загрузка — `create_file` с `base64Content` = `sha256:<хэш>:<путь>`.
- Поиск Drive отстаёт после переноса (показывает файл по старой папке, но с новым `parentId`) — норма.
- Товары «нет в наличии» по умолчанию скрыты (фильтр «В наличии»), видны по кнопке «Все» или при
  поиске (18.11). Позиции с неизвестным остатком не скрываются.
- Двери: лист «Двери», одна строка = один размер; карточка = Завод + Коллекция + Модель. Фото двери —
  «Модель».jpg в «Каталог → Двери». Колонка «Артикул» = «—» обязательна (README, «Сделано 24.11»).
- Перед пушем `index.html`: проверить синтаксис скрипта (`node --check`) и открыть страницу в Playwright
  с подменой ответа `script.google.com` (данные той же формы: `{cfg, items}`).
