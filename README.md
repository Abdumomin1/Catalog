# Каталог Maff в Telegram-боте — как устроен и где остановились

Последнее обновление: 18.11.2026. Этот файл — конспект для следующего чата: как работает каталог,
что уже сделано и с какого места продолжать.

## Как это работает

```
Кнопка «Каталог» в боте @maff_uz_bot
        │ открывает
        ▼
index.html (этот репозиторий, GitHub Pages)  ── быстрая оболочка, кэширует данные на телефоне
        │ берёт данные: EXEC + "?data=json"
        ▼
Apps Script, привязанный к Google Таблице «Каталог»
        ├── товары — листы таблицы «Каталог»
        ├── остатки — лист «Цены 1C» таблицы «Двери Дил» (по названию номенклатуры)
        └── фото — папка Google Drive «Каталог» (по имени файла)
```

- **Таблица «Каталог»:** <https://docs.google.com/spreadsheets/d/1JSCgXBTlrYnvWLD-bHXfp9DCtXOKgFXZEh1zn2bBoe4>
- **Скрипт** привязан к самой таблице (Расширения → Apps Script). Через Google Drive его код не виден.
  **Копия кода — в папке [`apps-script/`](apps-script/)** (прислана владельцем 18.11): `Code.gs` (сборка
  каталога, кэш, меню), `Каталог.html` (страница, которую отдаёт сам скрипт), `Диагностика.gs`
  (`diagnosePhotos` — сверка имён фото с номенклатурой). Файла «Claude» (меню «Подобрать названия из 1С»,
  «Ключ Anthropic») в копии нет. **Копия не живая:** правка здесь ничего не меняет — владелец вставляет
  код в редактор Apps Script и выпускает новую версию (Начать развертывание → Управление → Изменить →
  Новая версия). Если владелец правил скрипт сам — попросить свежую копию.
- **Адрес данных** — переменная `EXEC` в `index.html`. Проверить, что отдаёт каталог: открыть `EXEC?data=json`.
- **Каждый лист с товарами = категория** в каталоге: «Ламинат», «Плинтуса», «Подложка», «Двери»,
  «Стеновые панели и профили». Пустой лист в каталоге не показывается. «Настройки» — служебный лист.
- **Колонки листа «Ламинат»:** Завод · Толщина и класс · Коллекция · Артикул · **Номенклатура** · Толщина ·
  Класс · Фаска (+/−) · Длина · Ширина · Пачка (сколько плашек) · Падон · Порог («мало» ниже него) ·
  Приоритет · колонка O с галочкой без заголовка (её смысл неизвестен; у новых строк она пустая).
- **Колонки листов «Плинтуса» и «Подложка»:** Завод · Ед. · Высота/Длина · Артикул · Номенклатура · Порог.
  У «Плинтусов» с 24.11 ещё колонка G «Коллекция» (как группа 1С): по ней в каталоге заголовки групп.
- Колонки «Завод», «Толщина и класс», «Коллекция» — выпадающие списки умной таблицы (чипы). Новое
  значение (новую коллекцию) нужно сначала добавить в список колонки, иначе ячейка помечается красным.
- **Остаток** ищется по колонке «Номенклатура» в листе «Цены 1C» (колонка B). Название должно совпадать
  с 1С; лишние пробелы скрипт сам убирает.
- **Фото:** папка Drive «Каталог» (ID `1rsAAa7mngASsJ-kDwgLT69rKPP-wMGyO`), просматриваются все подпапки.
  **Имя файла = номенклатура + `.jpg`** (точь-в-точь как в колонке «Номенклатура»). Папка должна быть
  открыта по ссылке («Все, у кого есть ссылка — читатель»).
- **Кэш:** остатки перечитываются раз в 15 минут, папка с фото — раз в 6 часов (лист «Настройки»).
  Фоновое «ускорение» (`warmCache`, раз в 10 минут) пересобирает каталог, но список фото берёт из кэша.
  **Сбросить сразу:** в таблице меню «Каталог → Обновить сейчас» (`refreshNow` чистит и кэш фото).
  Потом открыть каталог в боте дважды (на телефоне свой кэш).
- **Как скрипт ищет фото** (`imageMap_`, `buildCatalog_`): по имени файла без расширения (любое
  расширение — .jpg, .png, .webp), затем по имени без знаков «/ , . - _ ( )», затем по цифрам артикула
  (только если такие цифры в каталоге у одного товара). При двух файлах с одним именем побеждает
  последний найденный — поэтому дубли опасны.
- **Новый товар:** строка в нужном листе (номенклатура — точно как в 1С) плюс фото в папку завода
  с именем «номенклатура.jpg».

## Как работать быстрее (для следующего чата)

- Иерархию «завод → коллекция → номенклатура» брать из выгрузки 1С (`.xlsx`), не гадать по имени.
- Списки Drive постранично: `parentId = '<папка>' and mimeType != 'application/vnd.google-apps.folder'`,
  `excludeContentSnippets: true`. Перенос — `update_file` с `parentId`, можно пачками параллельно.
- Код Apps Script — в `apps-script/`, переспрашивать не нужно (но он может устареть).
- Перед переносом в существующую папку посмотреть 2–3 файла в ней — так подтверждаются коды вроде RTK/RTS.
- `script.google.com` из облака закрыт — проверить выдачу каталога (`EXEC?data=json`) нельзя.
- Владелец включает режим **Auto**, иначе каждое действие с Drive требует «Разрешить».
